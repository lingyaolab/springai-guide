把 Spring AI 2.0.2 学到「能自己接进项目」

这不是官方文档的搬运，而是一套按工程落地顺序重排、每个结论都能回源码验证的教程。默认模型是 DeepSeek：便宜、国内直连、兼容 OpenAI 协议，适合把例子真正跑起来。示例全部是 Spring Boot 4 + Java 17，每一章都有能复制运行的代码、一次请求的完整链路、以及「你会撞到什么错」。

我该从哪儿开始

  1. 先花 12 分钟读「学习地图」
    它会告诉你三条主线怎么用、章节为什么是这个顺序、以及没有 API Key 能学到哪一步。
    → 00 学习地图
  2. 装好环境（约 25 分钟）
    JDK 17 + Spring Boot 4.1 + 两个依赖：spring-ai-starter-model-deepseek 与 spring-boot-starter-web。版本全部交给 spring-ai-bom。
  3. 跑通第一次对话（约 35 分钟）
    → 02 ChatClient：从 ChatClient.Builder 注入到 .call().content()，再到流式与多轮记忆。
如果你只想最快验证「这套东西能不能跑」

直接看 01 章的最小可跑：一个 Spring Boot 工程、三行 application.yml、一个 CommandLineRunner，补一个 DEEPSEEK_API_KEY 就能看到输出。

三条学习主线

① 跟做线：照抄能跑

  • 每章「最小可跑」都是完整工程结构，含 pom.xml 与配置
  • 代码里出现的每个 API 都能在附录 C 的速查表里查到出处
  • 目标是「先跑起来」，不追求先看懂

② 理解线：知道它在干什么

  • 每章「端到端」把一次调用拆成自动装配、 Advisor 链、HTTP 请求三段
  • 关键机制给分层图：谁装配谁、配置在哪生效、失败在哪一层

③ 避坑线：出错时知道看哪儿

  • 每章「陷阱与窍门」按「你会看到 X → 因为 Y → 改成 Z」写
  • 重点标出 1.x 到 2.0 的破坏性变更，网上大部分博客仍然停留在旧写法

已知边界
  • Spring AI 2.0 需要 Spring Boot 4.x。仍在使用 Boot 3.4/3.5 的项目请留在 Spring AI 1.0.x，不要把本站的依赖坐标直接搬过去。
  • 官方中文站（docs.springframework.org.cn）已经覆盖 API 参考；本站不重复翻译，只补「学习顺序、可运行工程、 版本差异与踩坑」。
